## 🚀 نحوه اجرا در محیط محلی

### پیش‌نیازها

- Node.js نسخه ۱۸ یا بالاتر و npm

### مراحل راه‌اندازی

۱. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/soheilabbasnia/soheilabbasnia.ir.git
   cd soheilabbasnia.ir
   ```

۲. **نصب وابستگی‌ها:**
   ```bash
   npm install
   ```

۳. **اجرای کامپایلر استایل‌های Tailwind CSS:**
   ```bash
   npm run watch
   ```

۴. **اجرای سرور محلی (Local Server):**
   ```bash
   npm run dev
   ```
